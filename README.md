# YelpCamp: The Web Development Bootcamp megaproject
### In this repository lies the project that puts in practice all technologies learned in the Udemy course "The Web Development Bootcamp", from tutor Colt Steele, which I took.

The platform serves as a place to review, register and find new camping sites all around Brazil (not with real data).

It uses Javascript along with Express as back-end server, MongoDB as database and Mongoose as ORM, EJS for templating, among other JS-centered technologies.
